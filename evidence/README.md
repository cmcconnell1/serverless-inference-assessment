# Evidence captures

Produced by `scripts/probe_providers.sh` on 2026-09-29 with no credentials. Each probe writes
three files: `<probe>.headers` (raw response headers), `<probe>.body` (raw body), and
`<probe>.meta` (provider, method, URL, HTTP status, capture time, body size). `dns.txt` holds
`dig` output for the provider's hosts, `asn.txt` the origin ASN of every resolved address
(Team Cymru whois), and `timing.txt` nine samples of DNS, TCP, TLS, and TTFB timings per
inference host. `run-<UTC>.log` lists every request and status.

| Directory | Hosts probed |
| --- | --- |
| `probes/baseten/` | inference.baseten.co (OpenAI route), api.baseten.co (management API and OpenAPI spec), status.baseten.co, docs and www |
| `probes/deepinfra/` | api.deepinfra.com (OpenAI route, native route, public catalog, OpenAPI spec, live metrics), status.deepinfra.com, docs and www |
| `probes/nebius/` and `probes/nebius_tf/` | api.studio.nebius.com and api.tokenfactory.nebius.com (OpenAI route, OpenAPI spec, Swagger UI, dedicated templates), status.nebius.com, docs and www |
| `probes/akamai/` | api.linode.com (regions, profile, OpenAPI spec), status.linode.com, techdocs.akamai.com (llms.txt, agent-skills index), www.akamai.com |

Probe names:

| Probe | Request |
| --- | --- |
| `models` | GET `<base>/models` |
| `noauth` | POST `<base>/chat/completions` with no Authorization header |
| `badkey` | POST `<base>/chat/completions` with a fixed invalid bearer token |
| `options` | OPTIONS `<base>/chat/completions` with an Origin header |
| `notfound` | GET `<base>/this-route-does-not-exist` |
| `openapi`, `openapi_tf`, `inference_openapi` | GET public OpenAPI documents |
| `public_models`, `dedicated_templates`, `regions` | GET public catalog or region endpoints |
| `live_metrics` | GET DeepInfra platform-wide live metrics (two samples, 30 s apart) |
| `status`, `status_incidents` | GET Statuspage `summary.json` and `incidents.json` |
| `docs_head`, `www_head`, `inference_head`, `mgmt_noauth`, `native_noauth`, `fastapi_docs`, `llms_txt`, `agent_skills`, `api_catalog` | Fingerprint and discovery requests |

Derived tables in `derived/` are regenerated by `python3 scripts/summarize_probes.py`.

## Character encoding

JSON bodies are re-serialized at capture time with every non-ASCII character written as a
`\uXXXX` escape. Parsed values are identical to the response; the stored file is pure ASCII.
Non-JSON bodies (HTML, plain text) are stored as received and may be normalized later by
repository character hygiene (typographic dashes and quotes rewritten to ASCII). In every case
the `body_bytes` and `body_sha256` fields in the `.meta` file describe the bytes as received,
and `body_encoding` records which treatment was applied. Re-run the probe script to obtain
byte-exact originals.
